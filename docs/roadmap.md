# Roadmap de reconstrucción

Este documento existe para hacer visibles los límites entre fases y evitar una
migración masiva difícil de probar.

1. Auditoría de solo lectura — completada.
2. Arquitectura y documentación base — completada.
3. Tmux mínimo desde cero, sin plugins — implementada; validación interactiva
   pendiente.
4. Starship con una única carga y configuración reproducible — bloqueada hasta
   cerrar la Fase 3A.
5. Shell modular: aliases, exports, functions y completion.
6. Adaptadores de terminal y guía de migración.
7. Git, fuentes y scripts de instalación explícitos.
8. Validación de reconstrucción en un Linux compatible.

Cada fase requiere prueba, documentación y confirmación antes de continuar.
