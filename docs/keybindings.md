# Atajos de teclado

Este documento existe para que los atajos sean descubribles sin inspeccionar
archivos de configuración. Se actualizará al final de cada fase que añada
atajos.

## Tmux — Fase 3A

| Atajo | Acción |
| --- | --- |
| `Ctrl+a` | Prefijo de tmux |
| `Ctrl+a Ctrl+a` | Envía `Ctrl+a` a la aplicación |
| `Ctrl+a \|` | Divide en paneles laterales |
| `Ctrl+a -` | Divide en paneles superior/inferior |
| `Ctrl+a h/j/k/l` | Selecciona panel izquierdo/inferior/superior/derecho |
| `Ctrl+a r` | Recarga la configuración instalada |

Los atajos predeterminados de tmux para crear y cambiar ventanas se conservan.
No hay atajos de plugins ni de terminal en esta fase.
