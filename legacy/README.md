# Referencia histórica aislada

Esta carpeta existe para conservar copias manuales de configuraciones antiguas
cuando ayuden a decidir qué comportamiento rescatar. No es parte de la
arquitectura activa.

Nada fuera de `legacy/` puede leer, cargar, enlazar, ejecutar ni depender de
estos archivos. Cada copia debe indicar su origen y fecha. No se guardan
secretos en esta carpeta.
